# Ultimate Rizz + Гатанки

Bilingual (MK/EN) website with the best rizz lines and classic Macedonian folk riddles.

## Features
- **Rizz Lines** – 75+ lines in categories (Smooth, Funny, Cheesy, Modern, Text Openers)
- **Language switch** – МК ↔ EN
- **Гатанки** – 24 traditional Macedonian riddles with reveal answers
- Random generator + copy buttons
