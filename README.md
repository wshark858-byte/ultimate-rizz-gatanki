# RizzLines.mk

**https://rizzlines.mk** — Bilingual (MK/EN) rizz lines + classic Macedonian folk riddles (гатанки).

## Features
- 75+ rizz lines (Smooth, Funny, Cheesy, Modern, Text Openers)
- Language switch МК ↔ EN
- 24 traditional Macedonian riddles with reveal answers
- Random generator + one-click copy

## Live
- Custom domain: **rizzlines.mk** (after DNS setup)
- GitHub Pages: https://wshark858-byte.github.io/ultimate-rizz-gatanki/

## Domain setup (GitHub Pages)
1. Register **rizzlines.mk** at a .mk registrar (MARnet accredited)
2. Repo → Settings → Pages → Custom domain → `rizzlines.mk`
3. At your registrar, add DNS A records:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
   - and/or CNAME `www` → `wshark858-byte.github.io`
4. Enable **Enforce HTTPS** in Pages settings

> Note: `.mk` domains usually require a North Macedonia resident or company (or trustee service).
